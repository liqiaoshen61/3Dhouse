# 栖居 · 双层住宅 Demo

## 打开

双击 `index.html`，使用 Chrome 或 Edge 打开即可。Three.js 已包含在 app.js 中，运行不依赖网络、不需要安装环境。

也可安装 Node.js 后运行 `node server.cjs`，访问 http://127.0.0.1:4173 。

## 操作

- 鼠标拖动旋转，滚轮缩放；手机可单指旋转、双指缩放。
- 1F、2F、整栋、展开切换查看；整栋中选房间会切换至对应楼层以免楼板遮挡。
- 悬停房间显示中文名称并高亮；点击房间或侧栏名称平滑聚焦。
- 完整墙体开关在低墙剖视与完整墙体之间切换；屋顶和名称可独立开关。
- 返回全景、俯视平面、自动漫游；手动操作会停止漫游。
- 图纸与说明中可查看原始图及建模假设。

## 建模依据和推定

优先依据 references 内两张原始图的尺寸与空间关系，未使用生成的清理图。
一楼室内约 57.4㎡、后院约 17㎡；二楼室内约 53.6㎡、露台约 2.7㎡。面积是原图标注，不是模型计算面积。

依据用户补充，楼梯采用直跑，两层错位并部分重合。二楼图以楼梯中心线与上端平台对齐到一楼；纵向平移约 -3.55m 为图纸估读。直跑梯段按原图 15 级与假定 3m 层高建模。此处的级高不作为建筑规范设计建议。

层高 3m、墙高 2.7m、门窗高度、屋顶形式、材质、植物、家具细节为概念示意；露台位置按原图左侧外挑区推定。未提供结构、立面或现场量测资料，因此外伸楼层的承重体系未建模。不作施工、结构或面积审核依据。

## 项目文件

- index.html / style.css：界面
- src/main.js：可编辑的 Three.js 场景、房间数据和交互
- app.js：已打包的离线运行文件
- references：原图
- preview.png：实际浏览器截图
- server.cjs：可选本地静态服务器

修改源码后：`npm install`，再执行 `npm run build`。依赖版本已固定在 package.json。

## 运行与检查

已用本机 Edge 的真实 WebGL 浏览器运行检查：四种楼层视图、房间聚焦、墙体/屋顶、自动漫游、移动视口和 file:// 离线打开。控制台无运行错误。Chrome 使用相同浏览器核心和标准 WebGL/ES 功能，但本次未单独启动 Chrome 验证。

重复静态构件使用实例化绘制，限制像素比及阴影贴图大小。家具细化后，三角面和绘制次数随视角变化；使用共享几何体与静态构件实例化控制开销。未作各类手机硬件帧率保证。

## 室内细化版本

现代简约配色：暖灰、白色与深胡桃木。新增圆角床品和坐垫、织纹地毯、抱枕与搭毯、床头灯和落地灯、餐具、柜门五金、厨房台面物件、书籍和浴室用品。装饰性陈设为设计补充，户型与两层错位关系保持不变。细节建模代码位于 src/interiors.js。

## 儿童房调整
二楼原次卧改为儿童房；移除床、床头柜、床头灯及床边地毯。原床头方向（图纸下侧墙）设置约 0.72m 高的矮书架和玩具架，保留中央活动空间及原衣柜。


## 地面铺装更新
一楼仅卧室保留顺铺木地板，其他室内区域使用约 1.2m × 1.2m 暖灰色大尺寸哑光瓷砖。二楼室内（含主卫）统一鱼骨拼木地板。后院、露台铺装与楼梯踏步保持原样。铺装纹理离线生成，跨楼板采用统一尺度与拼接坐标；源码见 src/flooring.js。


## 开放衣柜更新
一楼卧室、二楼儿童房和主卧衣帽区的衣柜统一改为白色金属开放框架，包含挂衣杆及薄层板，不设柜门和背板。原位置与占地保持不变。设计为货架式衣柜示意，并非特定宜家产品的精确复刻。源码见 src/wardrobes.js。


## 二楼洗烘区调整
原储物间改为开放洗烘区，移除入口与楼梯侧隔墙、原储物柜和收纳箱，保留儿童房隔墙及建筑外墙。洗衣机在下、烘干机在上，背朝楼梯、机门朝儿童房隔墙。模型中机门与隔墙约留 0.8m 间距，尺寸为布局示意。
